# Alt Staff Mode (Fabric, 1.21.11)

Клиентский Fabric-мод для модерации сервера.

## Возможности

1. **Авто-подпись бана.** Когда ты пишешь `/ban ник время причина`, мод
   автоматически дописывает в конец `- Вопросы? ВК » "Ответ"`.
   Текст «Ответа» редактируется в меню. Работает также для `tempban`, `banip`
   (список команд настраивается).

2. **Быстрый мут кликом по чату.** Клик по сообщению игрока подставляет в строку
   ввода `/mute Ник ` — остаётся дописать время и причину. Подпись «Вопросы?»
   при этом НЕ добавляется (она только для бана).

3. **Статистика.** Мод считает:
   - отыгранное время за сессию / сутки / неделю;
   - количество выданных мутов и банов (за сегодня / неделю / всего).

   Наказания считаются по сообщениям-подтверждениям в чате (например
   `Администратор "ТвойНик" замутил/забанил ...`). Ключевые слова и проверка
   собственного ника настраиваются в конфиге.

## Управление

- **Right Shift** — открыть меню (изменить «Ответ», посмотреть статистику).

## Файлы настроек

Создаются в папке `config/`:

- `altstaffmod.json` — настройки (текст ответа, шаблоны, ключевые слова, регулярки).
- `altstaffmod_stats.json` — накопленная статистика.

### Важные параметры `altstaffmod.json`

| Параметр | Назначение |
|---|---|
| `vkAnswer` | Текст «Ответа» (подставляется в `{answer}`). |
| `banSuffixTemplate` | Шаблон подписи бана. |
| `banCommandAliases` | Команды, к которым приписывается подпись. |
| `muteCommandTemplate` | Шаблон команды быстрого мута (`{nick}` — ник). |
| `gameMessageNickRegex` | Регулярка вытаскивания ника из системного чата (group 1). |
| `muteKeywords` / `banKeywords` | Слова-признаки наказания для статистики. |
| `requireOwnNameInStatMessage` | Считать наказание только если в сообщении есть твой ник. |

> Форматы чата у каждого сервера свои. Если клик-мут или подсчёт наказаний
> работает не идеально — подстрой `gameMessageNickRegex`, `muteKeywords`,
> `banKeywords` под формат своего сервера.

## Сборка

Нужен JDK 21.

```bash
./gradlew build
```

Готовый `.jar` появится в `build/libs/`.

> **Версии Fabric.** В `gradle.properties` стоят ориентировочные значения для
> `minecraft_version`, `yarn_mappings`, `loader_version`, `fabric_version` и
> версии Loom в `build.gradle`. Перед сборкой сверь их с актуальными сборками
> Fabric для 1.21.11 на https://fabricmc.net/develop/ и при необходимости поправь.

> **Важно про `ClickEvent`/`HoverEvent`.** Код использует новый API
> (`new ClickEvent.SuggestCommand(...)`, `new HoverEvent.ShowText(...)`),
> который появился в **1.21.6+** (актуально для 1.21.11). Если вдруг будешь
> собирать под более старую версию (1.21.1–1.21.5), эти вызовы надо заменить на
> старый вид: `new ClickEvent(ClickEvent.Action.SUGGEST_COMMAND, "...")` и
> `new HoverEvent(HoverEvent.Action.SHOW_TEXT, Text...)` — см. `ChatTracker.java`.

> ⚠️ В среде, где готовился проект, доступа к maven Fabric не было, поэтому
> финальная Gradle-сборка с зависимостями не прогонялась. Структура проекта,
> entrypoint и API-вызовы выверены под Fabric 1.21.11, но первую сборку
> прогони у себя и поправь версии в `gradle.properties`, если потребуется.

## Заметки по реализации

- Перехват и модификация исходящих команд — через `ClientSendMessageEvents.ALLOW_COMMAND`
  (оригинальная команда отменяется, отправляется модифицированная). Mixin'ы не используются.
- Клик-мут — через `ClientReceiveMessageEvents.MODIFY_GAME` (подписанный player-чат
  менять нельзя): сообщению добавляется `ClickEvent.SuggestCommand`. Ник берётся
  регуляркой `gameMessageNickRegex`.
- Время копится в `ClientTickEvents` и сохраняется периодически и при выходе.
